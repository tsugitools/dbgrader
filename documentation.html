DBGrader Help

Practice SQL in your browser. DBGrader runs SQLite locally, lets you explore the database, and grades your answer by comparing query results—not by matching your SQL text to a single “correct” string.

Getting Started

  1. Read the exercise prompt carefully.
  2. Use Run to try SQL and explore the database (not graded).
  3. When you think you are done, click Check Answer.
  4. If correct, your grade can be sent to the LMS. If not, read the feedback and try again.

Fresh database every time

Each Run and Check Answer starts from a clean in-memory database with the exercise setup applied. Changes from a previous Run do not stick around.

Typical flow

SHOW TABLES; DESCRIBE pantry_items; SELECT item_name, weight_oz FROM pantry_items WHERE weight_oz > 30; — then Check Answer

Learner Interface

  • Prompt — what you need to solve
  • Your SQL — editor (may already contain starter SQL from your instructor)
  • Run — execute your SQL or an explore command (not graded)
  • Check Answer — grade your submission
  • Reset — restore starter SQL and clear the result panel

Exploration vs grading

Meta-commands like .tables, SHOW TABLES, and \dt are for exploration with Run only. They are not accepted as a graded Check Answer—submit real SQL for grading.

Exploration Commands

These work with Run. MySQL- and PostgreSQL-style commands show a note that they were converted to SQLite.

SQLite shell style

CommandPurpose
.tablesList tables
.schema [table]Show CREATE statements
.indexes [table]List indexes
.databasesShow :memory:
.columns tableColumn info
.foreignkeys tableForeign keys
.describe tableColumns, indexes, FKs, CREATE
.helpCommand list

MySQL style

CommandPurpose
SHOW TABLES [LIKE 'p%']List tables
SHOW DATABASES:memory:
DESCRIBE table / DESC tableColumn info
SHOW CREATE TABLE tableCREATE statement
SHOW INDEX FROM tableIndexes

PostgreSQL (psql) style

CommandPurpose
\dtList tables
\dList tables and views
\d tableDescribe a table
\diList indexes
\dvList views
\l:memory:
\?Help

Still SQLite under the hood

Only these exploration helpers are translated. Your graded SQL runs as SQLite.

Tips

  • There can be more than one correct query—matching the expected result matters.
  • If row order is part of the exercise, use ORDER BY.
  • Use explore commands to learn the schema before writing your final query.
  • Read the feedback after Check Answer; it often points at column or row mismatches.
